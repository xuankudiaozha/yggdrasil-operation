# 内部写作输入合同

本合同的完整科学材料供一条 Scientific Author 线程使用。随后按[独立语言编辑合同](language_editing.md)提供同一选中文本、当前 profile、必要语言 Anchor、偏好及事实锁给两位编辑。

本技能的 [writing](writing.md) 包含原 AnchorRefine 写作流程，动态引用机制见 [Word/Zotero](word-zotero.md)。`anchor_refine_input.md` 是既有综述使用的内部证据映射接口。按实际存在的稿件续作。

INITIAL 接收可访问全文的主 Anchor、研究者批准的科学事实及适用统计/SIL 资料、现有批准写作方案和拟用图表或信息充分的示意材料。新计划使用一份作者可编辑的离线 HTML。既有 RRA Markdown 导出继续提供内部证据映射。已有批准写作方案可直接使用。若当前存在获批准的 HTML，章节／篇幅／段落和图表安排从其中读取。ITERATE 使用当前权威 DOCX 和新辅助 Anchor。综述以规范证据提取作为事实卡。

`rra.py export <研究目录>` 生成 `anchor_refine_input.md`，包括：

| 下游需要 | 规划模块提供的来源 |
| --- | --- |
| 锁定标题、核心问题、中心论点、范围与排除边界 | Round 1与Round 3已确认状态 |
| 正式层级与各节科学任务 | JSON中的唯一outline及章节question |
| 段落顺序、功能与论证路径 | Round 4段落计划 |
| 原始证据和真实Zotero标识 | 研究ID＋结果ID＋item key、DOI、来源及定位 |
| 推断所需上下文 | 对象、设计、方法、适用条件、局限、original/synthesis及association/causal区别 |
| 两类Anchor及主结构Anchor资料 | 每个Anchor的独立用途、可用材料和结构观察 |
| 冲突、缺口和过度推断边界 | 命题关系、段落限制/冲突、证据缺口和当前未决问题 |
| 图表与准备不足项 | 拟用文件清单及同一计划内Researcher TODO |
| 检索、筛选与最终参考文献数量 | 同一 `rra_v6_search_provenance.md` 的位置及Round 4去重容量复核 |

该文件是由当前科学状态派生的下游成果，当前交接和独立来源表仍各有唯一职责；不复制检索历史或完整书目。不要直接编辑它改变科学合同；补充证据／资料或更新段落后先重新map，再重新导出，已完成Round 4也可在批准大纲下重映射。已锁定命题的表述、推断类型或所需研究类型变更仍须issue、研究者确认与上游reopen。修复Zotero绑定使用显式refresh-library，保留科学选择并使旧派生计划失效。存在可能推翻论点的重大问题时先issue，经研究者授权重开Round 1或3；旧派生计划被移除，避免误用。没有可靠证据的段落保留明确缺口，不能以流畅措辞替代来源。

导出状态与写作启动状态分开。能生成段落骨架说明技术接口可读，不等于完整正文可立即启动：

- `ready`：live模式下已声明主结构Anchor全文和本地预期素材；下游仍需实际读取来源、遵守自己的输入合同。
- `needs_input`：计划已生成，完整主Anchor或必要素材仍缺失；同一计划明确Researcher TODO。只在可用科学材料范围内继续，不虚构缺失事实。
- `fixture_only`：测试输入和模拟选择，不得进入真实写作，也不能报告为真实INITIAL验收。

本地资料和拟用图表采用实际绝对路径；当前适配器对本地文件可检测存在性，对远程材料记录真实访问位置；远程阅读成功、全文完整性、科学支持关系必须由Codex通过实际工具核实。无预期图表可在批准范围内声明；该声明不覆盖下游对于确有拟用图表的要求，也不是以空文件绕过素材合同。

获授权的写作会话先读取内部 writing 模块和本文件、交接指向的证据索引及完整主Anchor；按照writing-plan组织全文。只借鉴Anchor的结构、密度和修辞功能，不复制连续原句，不照搬其研究结果或引文。保持已批准科学范围；综述不是其引用原始实验之外的新独立实验；摘要支持不得在正文中升级为全文验证。

Round 1–4 只生成规划与证据映射，不生成正文或稿件完成声明。内部 INITIAL / ITERATE 负责获授权的正文、唯一权威 DOCX、真实 Word 引用插入／刷新／验证和引用后书目；图表生成仍须既定授权。后续新增引用仍须记录实际检索时间、完整检索式或真实引文追溯方式、原始凭据、全部Search ID和Zotero身份：通过同一 `acquire` 追加来源，并在当前段落／图表论证位置登记后重新 `map`、更新来源表。新增证据若改变已锁定科学主线，先用原有issue／研究者确认／reopen流程处理；不增加新轮次或审批层。除非另有明确授权，Abstract与Conclusion沿用其默认保留/空白规则。实际调用或写作授权由真实研究任务决定；开发测试不自动授予正文写作权限。

当前项目已核验的 Zotero 集合是唯一写作集合；不因写作而创建另一套按文件夹命名的集合。非 RRA 项目可直接用批准的既有写作计划及其记忆，不要求将原生记录迁入这套四轮索引。保存检索与写作资料均遵守本地文档边界。
