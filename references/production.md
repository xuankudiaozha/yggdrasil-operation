# 生产与修订

三个入口都使用当前已采用的科学事实和直接结果，各自接受独立请求。当前 HTML 有相关安排时读取其最新段落、编号、补充位置与链接。若同一计划要求多种产物，可以并行准备。每个 DOCX 或工作簿由一个写入动作归并。校对其他产物中的现有引用或提示可能受影响的位置，跨产物同步遵循本轮授权。

## 论文

执行前读取包内[写作](writing.md)、[独立语言编辑](language_editing.md)和 [Word／Zotero](word-zotero.md) 合同。需要定向润色时读 [POLISH](polishing.md)。真实代理角色、模型配置、交叉核查和引用规则以包内合同为准。

- **INITIAL** 用可读全文的主 Anchor、批准的统计结果和当前 HTML。已有图表或足够清楚的示意可支持引用计划。整稿不等待正式图和表，仅暂停缺少科学依据的段落。若已有权威 DOCX，就在现有稿件内写作。第一次建立稿件才新建权威 DOCX。整稿批准明确涵盖题目、摘要、正文、结论、图注和表注时按该范围完成。原始研究用其现行结果或 SIL，综述用其已采用的证据映射。
- **ITERATE** 用当前稿件、一篇新辅助 Anchor 与原批准材料定向修订。**EDIT** 可在没有新 Anchor 的情况下修正指定内容。**POLISH** 可迭代指定自然段，聊天给出改写时不直接写回 Word，收到写回请求则只更新对应段落。已有稿件的独立修改无需新建统一计划或重启综述选题与检索轮次。
- **科学创作与语言编辑** 真实调用一条独立 Scientific Author 线程和两条独立语言编辑线程。作者读取相关证据、批准计划及 Anchor。两位编辑读取同一底稿的获授权段落、必要上下文及锁定事实，独立提议后互核。主控合并并做科学保真核对。纯语言请求直接进入编辑阶段。采用包内配置并预留代理席位。计划与结果核查不触发语言编辑。实际调用或引用工具不可用时准确报告已完成范围。
- **保存与核验** 在当前 DOCX 原位保留作者编辑、样式、真实 Zotero 字段和有效书目，除非研究者指定新位置。按现行合同插入并刷新真实引用，核验语义、数字和引文。图表注放在稿件中的约定位置，保留所需标记和现行期刊规则。不可用的图表或引用如实说明，依批准的表达范围完成独立稿段。RRA CLI 回执只记录实际写作结果，既有综述内部导出照旧，当前普通 HTML 可直接作为写作计划。

## 图

读取[图表规划与交付](visuals.md#图)。用现有绘图入口、样式和源数据，保留变量、统计量、分组、区间和必要标签。图内只保留读图需要的文字。在最新正式预览上核验图内文字。画布外的图注在稿件授权范围内写入，独立图可在现有审阅页面或聊天中给出必要说明。

- 已批准布局内的字号、颜色、显示格式或同口径已采用结果刷新可以独立制作。改变科学用途、对比、必要统计量或实质布局时，只重审受影响的图。
- 同一图对象导出同内容、同尺寸的 PDF／PNG，遵守项目的当前路径和命名。先准备并核对同版双格式，再以短期本机恢复措施成对替换。部分替换失败时恢复或完成同一版本，避免交付跨版本的一对。依现行合同核查可读性、裁切、尺寸和清晰度。

## 表

读取[图表规划与交付](visuals.md#表)。采用项目既有的统计表或原生结果，保留所有入选项、单位、精度及必要的缺失或不可估说明。表注归授权的稿件或现有审阅位置。为新表设计实质结构时只提交受影响项审批。

- 新工作簿沿项目约定，缺省为一个 Tables.xlsx，每个科学表一张工作表。已有工作簿时更新目标表，保留其他工作表、公式、格式及既有关联。先在本地临时件核对目标范围和未授权工作表，成功后替换当前文件。
- 局部更新用项目既有的工作簿编辑方式。整本导出用于新工作簿和明确授权的整本生成。保留实际数值，只在显示格式上处理精度。
