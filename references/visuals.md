# 图表规划与交付

从已采用的结果和本轮需要回答的问题选择图表。先查看真实对象再使用字段，保留源结果顺序或既定排序、人群与分母、时间单位、比较组、模型、阈值、检验族及不确定性。主结果、必要的阴性结果和不一致结果有明确图文位置。仅做版式调整或应用已采用结果时沿用既定输入和展示规则。

## 规划与审批

用[本技能 HTML 样板](../assets/production_plan.html)的图表区，把每项的用途、直接数据链接、正文引用位置和补充归属写在同一页。用与目标图相同比例的白底 SVG 简图画出轴、点线、区间、热图色块或流程，标记面板字母、图型与布局的读图要点。利用实际面板框面积除以各面板面积之和计算显示占比，分母不含留白和沟槽。几何结构可示意，结果数字和样本量只能来自真实证据。

表格计划显示工作表编号、完整列名、行数及实际前 3 行，少于 3 行时显示全部。横向滚动容纳宽表。结果未就绪时保留已确认字段并标明状态。计划阶段只交本轮 HTML。新增或实质改变面板结构、展示范围、行列结构或正文分配时，只提交受影响部分供批准。已有批准的对象在本轮授权范围内可直接制作或更新。

## 图

沿用现行项目程序、文件名、字体、色板和编码。森林图保留效应量、无效应参考值、区间及比较身份。曲线保留实际支持范围、观测单位和既有不确定性，按需要保留风险集与截尾标记。热图沿用已采用的缩放、色标范围、缺失编码和行列映射。观察值、既有模型拟合与示意内容应能区分。带外部素材的示意图沿用项目的来源、修改许可、署名和技术／临床核对，不把插画当作统计或机制证据。

从同一个已批准图对象保存 PDF 与 PNG，核对实际物理画布、内容、版式和边界一致。同一轮先写入本机临时目标，再核对并成对替换当前文件；遇到部分替换失败则恢复或完成同一版本。PDF 优先保留矢量元素和可编辑文字，PNG 按已采用的期刊分辨率输出。无期刊要求时，普通科研图可用 300 dpi，细线图按需要提高。可用下列写法接入本项目已有对象、尺寸和临时目标。Python 示例需要 Matplotlib，R 示例需要 ggplot2。

```python
import matplotlib as mpl

# figure is the approved Figure at its final physical size.
with mpl.rc_context({"savefig.bbox": None}):
    figure.savefig(staged_pdf, format="pdf", dpi=dpi)
    figure.savefig(staged_png, format="png", dpi=dpi)
```

```r
ggplot2::ggsave(staged_pdf, plot = figure, width = width_in, height = height_in,
                units = "in", device = "pdf", dpi = dpi)
ggplot2::ggsave(staged_png, plot = figure, width = width_in, height = height_in,
                units = "in", device = "png", dpi = dpi)
```

**正式预览复核。** 查看当前实际渲染的整幅图并放大各面板，同时核对源绘图或排版代码。面板字母引向图形，保留读图所需的轴与单位、刻度、组别、图例、标尺、事件标记和必要统计量。把草图提示、长解释、方法、完整图注和结论移出整张画布，连同原有页边文字一并检查。图注写到获授权稿件的对应位置，独立图可在现有审阅位置或聊天给出。检查最终尺寸的字号、遮挡、裁切、编码和分辨率。有问题时修正源代码并重出同版 PDF／PNG。图无法实际渲染或检查时报告未核对部分。

## 表

数据来自现行科学表或原生结果，全部获采用行、列、单位和有效精度随表交付。缺失和不可估沿用项目表示。数位、百分比与对齐只改显示。保留标识符的前导零。Excel 无法精确保存的标识符或数值按需保留为原始文本。字符串按文字写入，科学值不因格式化、列宽或条件筛选被改动。

新制全套默认在一个 Tables.xlsx 放置获批准工作表。现有工作簿中的局部更新针对当前工作表的授权范围，应沿用已有 Excel 或项目程序。在 Python 可用 openpyxl 编辑该工作簿，复杂对象的工作簿优先选择能保留它们的项目工具。先临时保存并重开核对目标表的行列、实际数值和类型，保留其他工作表、公式与引用、格式、合并和必要对象，再更新当前路径。图表并行制作时由同一写入动作汇总工作簿。仅当获授权生成整套文件时才从新工作簿导出全部工作表。

**交付核对。** 对照实际结果、图表与对应正文引用，确认标题、编号、面板、补充归属、图注和表注一致。独立图表任务报告发现的跨产物影响，按本轮授权更新。默认交付本轮获批的 PDF／PNG 对和一个工作簿，源码、编辑源、图注与表注使用其现行归属。
