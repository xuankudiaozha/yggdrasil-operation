# Yggdrasil Operation 调用提示词

正式文字沿[主写作方案](writing.md)的单线程科学作者与[双编辑互核](language_editing.md)。可追加“本次两位语言编辑使用 `gpt-6.2-sol/high`”覆盖编辑设置。纯语言请求直接提交选中的完整原文，并给出相关表达偏好。

所有 `<...>` 替换为实际信息。Round 1–4 每轮完成后换新的真实聊天。写作由实际请求启动，可从批准计划直接进入 INITIAL／ITERATE。已有初稿的段落迭代进入 [POLISH](polishing.md)。

| 功能 | 可直接使用的提示词 |
| --- | --- |
| 既有分析结果统一规划 | `$yggdrasil-operation 读取<实际结果路径>，先给我一份可编辑的离线 HTML，标明篇幅、段落及图表引用位置。待我批准具体生产范围后开始。` |
| 自动判断当前阶段／恢复 | `$yggdrasil-operation 研究目录：<绝对路径>。先读项目唯一记忆和当前状态，判断当前阶段，继续已授权且不依赖待确认选择的工作，不重建已有流程。` |
| 1 科学问题探索 RQE | `$yggdrasil-operation Round 1。领域：<领域>；研究目录：<绝对路径>。基于真实文献探索证据张力、竞争解释和最强反证，与我讨论，成熟后比较三种有实质认知增量的选题，由我确认。` |
| 2 检索／筛选／Zotero | `$yggdrasil-operation Round 2。读取<研究目录>的已锁定问题，执行真实检索、去重与初筛，建立并核验项目 Zotero 集合，区分科学和结构 Anchor，保存实际检索回执及来源统计。` |
| 3 标题／大纲／容量协商 | `$yggdrasil-operation Round 3。读取<研究目录>，依据现有证据给三套科学重心不同的英文标题和完整大纲，解释命题、论证路径、文献容量及范围代价，等我确认唯一方案。` |
| 4 精读／段落映射 | `$yggdrasil-operation Round 4。读取<研究目录>的锁定结构，按自然段精读和映射证据，核对推断强度、反证、唯一来源数量与图表用途，导出内部写作计划，不提前写正文。` |
| 5 INITIAL 全文初稿 | `$yggdrasil-operation INITIAL。研究目录：<路径>；主写作 Anchor：<全文路径或可访问来源>。按已批准计划和事实材料生成／续写唯一权威 Word，复用既有 Zotero 集合并插入真实动态引用。<摘要与结论是否已授权>。` |
| 已有项目直接写作 | `$yggdrasil-operation INITIAL。读取<项目记忆路径>和<批准的写作计划>，主 Anchor 为<来源>，拟用图表为<实际路径或已批准的无图表范围>。沿用项目原生证据与记忆，不新建四轮 RRA 状态，完成已授权的英文 Word 工作稿。` |
| 6 ITERATE 辅助锚迭代 | `$yggdrasil-operation ITERATE。项目：<路径>；当前权威 Word：<路径>；本轮新辅助 Anchor：<来源>。沿用冻结科学与人工编辑，学习有用写法后原位改写，不为达到比例而改写，报告各实际章节的近似改动。` |
| 7 POLISH 指定段落 | `$yggdrasil-operation POLISH。读取<当前稿件或粘贴原文>，沿用批准的写作方案，仅改<段落位置或首句>。目标是<语法句式或段内论证>，请在窗口给出干净版本。` |
| POLISH 续改或换段 | `$yggdrasil-operation POLISH。复用上轮有用的写法。这一轮润色<同一段的当前版本或另一个指定段落>，保持已有事实和引用。` |
| 综述实质综合优化 | `$yggdrasil-operation 优化<当前权威Word>的综述表达。沿用批准结构和来源，解释指标后给关键量化比较，明确年龄／干预／随访起点，解释异质性及其意义，区分原作者解释与综述假说，减少无实质作用的防御性结尾。<如执行辅助锚迭代，给新Anchor>。` |
| 引文／Zotero／Word 完整性 | `$yggdrasil-operation 检查并修复<稿件路径>本次涉及的引文：逐句核实实际支持、复用项目集合、核对动态字段和可见引用、用 Zotero 刷新仅含已引用来源的书目，报告无法完成的环节；保留未引用库条目。` |
| 补充证据与同步稿件 | `$yggdrasil-operation 为<研究目录>中<明确问题或段落>补充真实证据，按现有索引追加来源和映射，再同步权威稿及动态引文；不改变锁定科学主线，重大冲突先说明影响。` |
| 已授权重大科学修订 | `$yggdrasil-operation 研究目录<路径>。我批准将<旧范围／论点>改为<完整新范围／论点>。记录实际授权，重开受影响的选题或结构阶段，保留历史来源并重审筛选和映射；不要把它当普通语言润色。` |
| 故障恢复 | `$yggdrasil-operation 读取<项目路径>，定位<检索／集合／映射／Word引用>故障，只修复实际失效环节；保留已核科学选择、人工编辑与成功证据，报告实际恢复情况。` |
| 明确停止某独立选题 | `$yggdrasil-operation 我明确停止<选题目录>。核对共享依赖后按保留合同仅留最简本地交接，保留 Zotero 与其他项目使用的资料，清理该选题独占的冗余详细输出。` |

“综述实质综合优化”和局部引文修复是有范围的编辑请求，不自动要求新 Anchor 或再次跑完整 ITERATE，也不授权新统计、扩大证据池或创建图表；涉及来源池扩展按项目既定授权处理。

POLISH 按当轮选择限制编辑及交付范围。同一聊天可以续改或切换段落。明确要求写回时使用当前稿件和相应字段保留规则。
