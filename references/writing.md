# Anchor-guided manuscript writing


## Integrated entry and state

This module includes the AnchorRefine writing and review-synthesis rules. INITIAL and ITERATE are writing modes, not additional mandatory research rounds. Scoped prose/citation fixes may run directly without a new anchor; label their execution receipt EDIT instead of pretending a secondary-anchor run.

For iterative refinement of selected paragraphs in an existing manuscript, use [POLISH](polishing.md). The same writing workflow applies within that scope, using the existing approved plan and current text. Apply the Word-specific rules when Word writeback is authorized.

- For an RRA-managed project, read the declared current handoff and evidence index, plus the legacy `anchor_refine_input.md` evidence map. Use the current approved and author-edited HTML for headings, budgets, paragraph order and display callouts when present. Read [writing input contract](writing_input_contract.md) for provenance, new citations and upstream revision. Never regenerate an existing manually edited DOCX from an old plan as a blanket replacement.
- For a project with its own approved plan/memory (including an existing review), use those inputs directly; do not initialize or simulate four RRA rounds. Review evidence extracts and approved claims serve as fact cards; do not demand statistical SIL cards for a review that did not run models. Original-research writing still uses its actual approved statistical/SIL materials.
- Keep the first writing priority throughout planning and prose. For a thematic review, use the explanatory-synthesis rules below wherever its sections fall; do not force Introduction/Methods/Results/Discussion or assign revision percentages to nonexistent sections. Estimate changes by its actual sections without a new quota.
- Existing manuscript handoff or project memory takes precedence. If RRA is the only current-memory system, use `writing-receipt` in the same handoff (see [state contract](handoff_contract.md#写作回执)); otherwise update the existing system and give the receipt in chat. Do not create a parallel manuscript_handoff.md just to satisfy this module. For substantive changes to that current specification, follow the active workspace instructions. Record the change and its basis once in existing equivalent history or local `history.jsonl`, then update the affected current entry. Keep three-level ownership, do not log unchanged or ordinary stylistic edits, and do not copy manuscript revision receipts into current scientific memory. A history entry cannot authorize changes to frozen science.
- Any authorization already recorded for Abstract/Conclusion, specific sources or restructuring overrides the defaults below. Writing is a working-draft task, not publication-readiness certification.

## First writing priority — section purpose

**Choose information for the section's scientific purpose:** Methods explains how the study was conducted; Results reports what was found; Discussion interprets the findings and their contribution. Explanatory synthesis belongs in Discussion and review arguments, not in every Results sentence or paragraph ending. Apply the corresponding anchor section's responsibility, information selection and density to prose, headings, transitions and legends, rather than merely borrowing wording. Thorough verification does not require publishing every audit detail. Delete generic defensive language; retain qualifications that change interpretation or meet reporting requirements, without replacing them with unsupported positive claims.

## Mission and authority

The approved default uses one **Stage 1 Scientific Author** thread for the complete authorized draft or substantive revision. Start it with one native `collaboration.spawn_agent` call using `model="gpt-6.1-sol"`, `reasoning_effort="xhigh"`, and `fork_turns="none"`. Pass the approved inputs. Honor explicit model or effort overrides. The author organizes the entire authorized manuscript against its approved outline, gives sections distinct scientific functions, and carries the argument across sections. Keep drafting, synthesis and any author follow-up in that thread.

The author owns scientific content, Anchor use, structure and main/supplement placement. On the completed scoped draft, run [Stage 2](language_editing.md) with two independent editors who propose and cross-check language changes. The parent merges the confirmed changes and checks their fidelity. Language-only work passes the original selected text directly to Stage 2.

Produce a concise, natural, high-level medical-journal **working draft** with clear, evidence-supported scientific claims. This is a **rewriter**, not an independent scientific reviewer, statistical analyst, or publication-readiness certifier. Learn writing rhythm, information order, headings, and rhetorical functions from multiple anchors; express **only the researcher's approved scientific content**. Borrow writing structure without copying continuous source wording, assembling copied passages, or mechanically substituting variable names.

**Anchor controls writing; SIL controls facts.** Anchors guide section responsibilities, information selection, style, paragraph organization, density, and argumentation; SIL, actual models, and approved research materials determine scientific facts. Never invent methods, replace actual parameters, or change results to match an anchor. Mandatory journal requirements and applicable reporting standards take precedence over brevity.

Within that writing priority, preserve frozen science and necessary input completeness, use authentic and relevant citations, and write concise publication-style prose with low user-review burden. Do not add analyses, statistical diagnostics, Bootstrap, extra validation gates, metrics, or scientific review agents.

The author owns necessary scientific coverage and approved information allocation; the independent editor owns sentence-level economy and expression. Neither stage expands text to satisfy a revision percentage.

## 1. Resolve mode and inputs

- **INITIAL**: Primary anchor, approved science and applicable statistical/SIL cards, the project's approved writing plan, and intended figures/tables or informative schematics. For new plans, use one author-editable offline HTML. The existing RRA internal export still supplies evidence mappings where used. An adopted legacy plan can be read directly without creating a second plan. Create or continue the one authoritative `.docx`.
- **ITERATE (Run N)**: Current authoritative `.docx` + one new secondary anchor; reuse the previously approved research materials and constraints. A new anchor alone is sufficient to initiate the next writing run once the current source and manuscript are accessible. Run numbering is a writing revision sequence, **not** a new statistical EXP/runid.
- User-supplied constraints override defaults. Infer established input paths from the current manuscript project; do not invent source files or ask again for already available inputs. If any essential input is genuinely absent, work on safe available material and specify the blocker; do not fabricate missing findings.
- Read the project's existing `manuscript_handoff.md` and declared scientific/formatting contracts before either mode; preserve their approved scientific boundaries and output choices. Do not require a new handoff file if none exists.
- Respect any pre-existing ARS scientific-facts/formatting contracts. Do not repeat upstream statistical modeling, scientific review, figure generation, or study selection.
- Keep nonessential pending parameters and unconfirmed details out of manuscript prose; do not fill it with process language such as "not yet determined" or "currently unconfirmed."
- Record missing details briefly in a separate **Researcher TODO** block in the run receipt, or the existing handoff TODO location if declared; do not create a separate file or place these tasks in manuscript prose.
- Missing core models, primary endpoints, or information necessary to interpret conclusions block the affected text, not safe work elsewhere; never present them as confirmed or adopt an anchor's default parameters.

**Frozen:** approved study definitions, models, effect estimates, confidence intervals, P/q, population, table/figure scientific content and numbering, approved result-selection decisions, and writing-plan choices. Anchor is writing guidance, never substitute research evidence. Discrepant facts across approved inputs are referred to the researcher, not silently reconciled.

## 2. INITIAL — map primary anchor to our science

1. Read the accessible full primary anchor, including relevant section headings and citations. Identify each source sentence's **rhetorical function**, not a sentence to copy.
2. For each usable function, apply `MATCH` (rewrite from our approved facts), `PARTIAL` (retain only applicable function), `DROP` (remove inapplicable block), or `INSERT` (our necessary but anchor-absent content, written independently). Match sentence-by-sentence for comprehension; write coherent **natural paragraphs**, not rigid one-to-one sentences.
3. Use the approved writing plan for order and coverage. Map all supplied statistical cards and described figures/tables to narrative, table/figure callouts and legends, or authorized supplemental references. **Coverage does not require repeating every statistic or table number in prose; follow the section policies below without changing approved result selection.** Never silently discard a required input or invent a value from a schematic.
4. Learn the anchor's headings: hierarchy, brevity, syntactic pattern, and editorial style. Rewrite corresponding titles around our scientific claims. Delete sections we did not study; generate necessary extra sections in a matching style. Avoid verbose AI-style declarative headings; 3–7 English words is a flexible reference, not a quota. Do not force headings into an Introduction whose style lacks them.
5. Verify and insert the citations needed by the **new** manuscript under §4 and [Word/Zotero contract](word-zotero.md); never transplant an anchor's reference merely because it occupies an analogous position.
6. Write the one authoritative Word document. By default leave **Abstract** and **Conclusion** unchanged or blank; do not map/rewrite them without explicit authorization. Do not embed figure/table images or full tables; leave callouts in text and put Figure/Table legends **at the manuscript end**.
7. **Once after the initial drafting:** reconcile Results numerical expressions and figure/table references against the frozen cards. Check n, denominators, group contrasts, directions, units, estimates, CI, P vs BH-FDR q, adjustment models, and panel labels. Correct transcription only; do not rerun models or change scientific decisions.
8. Send the authorized draft to the two independent editors with minimal context. After reciprocal review, check the accepted edits against the source and apply them through the field-safe Word path. Keep the source version and edit provenance in the existing history or receipt.

### Methods — anchor-constrained exposition (both modes)

- Follow the primary anchor's corresponding Methods modules, descriptive hierarchy, information selection and statistical density. Use the project or journal's scope and length target; keep space proportional to the scientific role of each actual analysis.
- Keep the core design, population/time definitions, major variables, core models, important adjustment factors, missingness, multiplicity and decisive thresholds or settings in the main text. Preserve material methodological differences and information required for scientific reproducibility, interpretation or reporting. Leave other detail with its existing owner or in actual authorized supplementary material; never invent a Supplementary Methods section or imply that absent material exists.
- Describe how the study was conducted without transcribing `Parameters.md`, logs, diagnostics or SIL as an execution or acceptance manual. Default parameters, internal hashes, random seeds, caches and parameter-management records enter the main text only when scientifically necessary or required for reporting, not merely because they were verified. Do not present the completeness of internal records as a study method or contribution.
- When candidates are selected, state the actual ranking principles and retained counts concisely; explain material ties or researcher adjudication once in Methods or existing table notes/supplements. Preserve the real decision without repeating it throughout the narrative or recasting it as a unique automated ranking.
- **First-qualified anchor for a new Methods module:** when the primary anchor does not cover an actual analysis module being drafted, search published real studies online and stop at the first sufficiently matched paper whose full-text methods can be verified. Use its structure and descriptive hierarchy to describe our actual methods in the author's own words. A single qualified source suffices for a simple module. Ordinary paragraph polishing reuses the available approved anchor. This targeted methods reference does not start another secondary Run.

### Results — finding first (both modes)

- Open with a concrete count, direction or effect, then give **necessary statistical evidence → supporting result or figure/table callout** within the approved writing plan. Report multiplicity-adjusted findings when that is the adopted analysis. Remove vague lead-ins that name no finding; do not follow SIL execution order, explain mechanisms or scientific implications, or substitute internal input/output and finite-result counts for scientific findings. Retain actual eligibility, main-analysis sample sizes, denominators and failures where they affect interpretation.
- **A — Core:** retain the sample sizes, effect estimates, 95% CIs, and appropriate P/q values necessary to support the main hypothesis.
- **B — Supporting:** summarize direction, stability, and statistical significance of adjusted models, secondary analyses, and sensitivity analyses briefly; let tables carry detailed values.
- **C — Noncore:** secondary null findings, weak support, and repetitive analyses may take one accurate sentence, such as "The association was attenuated after adjustment," "The association was no longer statistically significant," or "No statistically significant association was observed." Nonsignificance is not evidence of no effect; distinguish P from FDR-adjusted q.
- Prespecified primary outcomes and findings that materially challenge the central conclusion must not be downgraded or omitted because they are negative; preserve approved result-selection decisions.
- Avoid repeating every model's β, CI and P or listing every candidate and secondary score. When full values are in an existing figure/table, select representative results for prose while preserving direction, significance decisions, adjustment status and important exceptions. Concision must leave necessary results verifiable in the approved manuscript, figures/tables or actual supplements.

### Discussion — claim first (both modes)

- Make clear what the study adds to existing knowledge. Use the corresponding anchors to organize **contribution → interpretation of findings → specific scientific or clinical value**, with relevant literature and only necessary local boundaries. State what the findings support before limitations; avoid numerical recitation and generic importance claims.
- Use confident language supported by the evidence, such as "These findings suggest...", "Our results support...", "These observations highlight...", or "This association may reflect...". "Genetic evidence supports a potential causal relationship..." is appropriate only when the actual genetic evidence supports it; never automatically elevate observational association, statistical mediation, or genetic instrumental-variable analysis to a proven biological causal mechanism.
- Explain each substantive limitation fully once. Group major limitations by their distinct interpretive impact within the user or journal's requested scope and place them in the closing Limitations passage; retain a brief local boundary only where essential. Do not conceal material limitations or mechanically repeat causal caveats, residual confounding or calls for validation in every paragraph.
- Apply the first writing priority to paragraph endings: summarize the substantive comparison or implication rather than defaulting to generic caution or a call for further research.

### Abstract and Conclusion — when authorized (both modes)

End with the supported main findings and only the boundaries needed to interpret them. A generic list of what the study cannot establish must not replace its scientific conclusion; preserve evidence strength and do not add findings, mechanisms or efficacy claims.

### Review manuscripts — explanatory synthesis (both modes)

- **Answer the heading's scientific question.** Organize paragraphs around what the reader should understand, rather than a succession of papers or a list of measurements. Where interpretation requires unfamiliar measures, explain their meaning before using them and carry the same measures into the substantive comparison; propose a major change to an approved outline under the existing authorization rule.
- **Make selected evidence concrete.** For findings that anchor the review's argument, reference values, clinically meaningful contrasts, or prognostic associations, report the available group/comparator values or effect estimates, distribution or range, population, units, and uncertainty needed to interpret them. State relevant age/stage, measurement method, and reference-group provenance; distinguish a reference distribution from a diagnostic threshold. Do not reproduce every paper's numbers or invent a universal normal range. Use an authorized table or figure when it conveys the reference more clearly; report unavailable essential values through Researcher TODO.
- **Give time an explicit origin.** Distinguish chronological age or developmental stage, age at intervention or baseline, and elapsed follow-up. Replace ambiguous terms such as "early" or "at one year" with the source-supported interval and reference event. Do not assemble cross-sectional age groups into a longitudinal trajectory.
- **Synthesize the comparison.** After presenting differences, explain their direction, size, persistence, or relative timing when the evidence permits, rather than ending at "measures differ" or "changes occur at different rates." Identify the actual phenotypes behind general labels. Compress corroborating studies around the shared finding while preserving material exceptions; do not rank rates, contributions, or risks from incomparable studies.
- **Explain heterogeneity.** Where evidence permits, replace "some patients" or "abnormality persists" with the observed subgroup, frequency or distribution, location, combination of features, and association with the outcome. Distinguish what is common from what predicts harm; explain which findings bear on compensation, stability, progression, or another review-specific outcome without inventing a hierarchy of contributions.
- **Use interpretations to explain findings.** Read relevant source Discussion passages for proposed explanations, not just Results for values. Connect observed patterns to mechanisms or competing explanations where supported, distinguishing measured findings, the original authors' interpretations, and the review's own synthesis or hypothesis. Attribute author interpretations to their sources; do not present them as demonstrated mechanisms or invent explanations for missing comparisons.
- **Keep evidence in service of the review question.** Intervention studies and technical methods may illuminate the phenomenon, but should not displace its description with treatment-effect attribution or an imaging-method catalog unless that is the approved topic. Prefer space for the defining features, comparisons, and explanations over repetitive methodological commentary.
- **Keep search reporting concise and reproducible.** Use a suitable review anchor for exposition. In the main text, state the actual sources, dates, scope, and selection approach at the level required by the review type; place complete queries and necessary search details in an authorized supplement. Put selection counts in their appropriate methods/results or flow diagram, without turning the search-strategy paragraph into a retrieval inventory; preserve required reporting and actual coverage limitations.
- **Integrate figures and tables into the argument.** Link each intended asset to the passage whose finding or concept it explains, with a relevant callout and an informative legend; revise or flag an asset with no clear narrative role rather than inserting an arbitrary callout. A proposed visual should resolve a defined comparison or spatial/temporal relationship using source-supported content. Follow existing figure-generation authorization and the end-of-manuscript legend contract; this guidance does not authorize new assets or embedded figures.

## 3. ITERATE — one secondary anchor per run

1. Read the new anchor and current `.docx`. Identify useful writing moves relevant to specific paragraphs/sections. Existing successful prose carries forward. An unsuitable new anchor can yield little or no change.
2. Compare meanings at sentence level, but **reconstruct at natural-paragraph level**. Freely smooth syntax, sequence, transitions, repetition, split/combine sentences, and paragraph ordering when scientifically safe. Do not build claim-unit inventories, multi-grade rubrics, LLM judge panels, or scientific quality scores.
3. Use **section-specific soft revision ranges** for every secondary Run. Percentages describe expected textual modification of the current section draft, not similarity to an anchor, scientific improvement, or paragraph-coverage quotas. Estimate actual change reasonably; no new measurement system is required. Exclude Abstract/Conclusion, bibliography, legends, and headings.

   | Section | Suggested revision range |
   | --- | --- |
   | Introduction | 0%–15% |
   | Methods | 0%–10% |
   | Results | 0%–15% |
   | Discussion | 15%–35% |

   There is **no mandatory minimum**, including for Discussion: a successful paragraph or section may remain 0% changed. Do not mechanically replace synonyms or expand text to meet a range. Factual errors, major structural problems, and necessary scientific corrections are not constrained by the upper bounds; frozen science and the approval boundary in step 6 still apply. Across anchors, improve expression rather than manufacture continuing textual change.
4. **Section behavior**: retain the successful Introduction strategy and wording unless improvement is needed; apply the Methods/Results/Discussion policies in §2 to both modes. Preserve scientific qualifiers and all retained numbers while reducing repetitive prose. Abstract and Conclusion are skipped unless specifically authorized. Meet applicable reporting requirements without adding a generic checklist or a new validation phase merely to rewrite prose.
5. Preserve *claim strength* internally during rewriting: do not convert association to causation, hypothesis to established mechanism, uncertain to certain, or prediction to intervention. Preserve population, comparison, temporality, model qualification, and negation. If an expression cannot be rewritten safely, keep it. Researcher retains scientific authority; no separate verification phase is required.
6. If a **major defect** calls for deep restructuring or a changed scientific rationale, do not execute that deep change without additional approval. Ordinary stylistic editing continues elsewhere. Note only the important concern/proposal in `revision.md` (§6).
7. When deleting/replacing cited text, remove its now-orphaned Word citation insertion point; **retain the literature item in the Zotero collection**. Any new factual statement needing support follows the same online verification and dynamic-citation insertion protocol as INITIAL. Recheck numerical/source mapping **only in Results portions touched this run**, not the whole manuscript.

## 4. Citation-grounded rewriting — mandatory for both modes

- For **every adopted citation-bearing argument** from an anchor, determine what the *new* statement claims and find the actual supporting literature online. Look up primary source/PubMed/publisher/DOI; verify bibliographic identity and the **specific claim supported**, not just existence of title or DOI. Consult full text or relevant passages when a claim exceeds the abstract's verifiable scope.
- Reuse a cited paper only when it still supports our altered statement. Otherwise find a genuinely supporting substitute, rewrite more narrowly, or omit unsupported content. Do not invent papers, DOI, numerical findings, mechanistic evidence, or citations.
- Also locate authentic support for newly inserted literature-dependent statements, even if not borrowed from an anchor. A claim without confirmed support must not masquerade as referenced fact.
- Every actually used paper must be in the **existing verified project Zotero collection** (reuse the upstream RRA collection; for standalone work without one, default to the project-folder-named collection) and inserted in Word as a **genuine editable Zotero citation field**, using a compatible Word/Zotero integration. Keep uncited/deleted papers in that collection. Refresh bibliography using Zotero; it should list the Word-cited sources, not every library item.
- If live Zotero access, integration, web search, or full-text verification is unavailable, **do not claim successful library insertion, field creation, or source verification**. Make the safe prose edits that are possible and report precise unresolved citation tasks. Do not fake dynamic fields with typed author–year or bracketed numbers. Follow the [Word & Zotero contract](word-zotero.md), including its verified Windows automation path when needed.

## 5. The single authoritative Word manuscript

- INITIAL creates one agreed manuscript `.docx` if none exists. ITERATE **edits that same file in place**. No auto-generated `run1.docx`, `final2.docx`, parallel drafts, or persistent backup copies. Use a separate path only when the researcher requests it. Temporary files needed for atomic save may be removed after successful replacement.
- Preserve Word styles, sections, headings, figure/table callouts, Zotero field codes, and actual citation links. Never call Zotero **Unlink Citations**, flatten fields, or use blanket paragraph replacement that would destroy fields. Use capable Word/Zotero editing mechanisms; a DOCX library alone does not guarantee dynamic-field insertion.
- In absence of a journal-specific format, use the established medical-manuscript default: Times New Roman, 1.5 line spacing, conventional ~2.54 cm margins, continuous line numbers, and APA-style Zotero citations unless a journal or approved project citation style already applies. No embedded figures/tables; References precedes the closing Figure/Table legends. Preserve one clean manuscript.
- Check document openability/layout and citation-field survival as a **technical integrity check**, not a second scientific peer review. Optional read-only helper: `python scripts/docx_zotero_probe.py <manuscript.docx>` before and after edits; zero or changed counts require interpretation, not automatic proof of loss.

## 6. Selective `revision.md` (secondary runs only)

- Create/update **one** project-local `revision.md` only to surface **important, identifiable** language/structural defects, unsafe scientific-expression changes, evidence/citation conflicts, input-to-text conflicts, or deep-restructure proposals. Ordinary stylistic changes are silent.
- Each entry is concise: `Original` (actual problematic sentence/paragraph), `Issue` (one-sentence concrete problem), `Revised` (applied replacement or clearly labeled proposed replacement). When deep change is pending authorization, **do not apply** the `Revised` proposal to Word.
- Overwrite entries for the **current run** instead of endlessly appending historical logs. The researcher may manually copy any previous `revision.md`. If none exists and no important issues arise, create no file; if an old one exists, avoid presenting stale entries as current-run issues (clear or mark none for this run without adding another file).

## 7. Stop and report

- Apply Stage 2 to authorized prose in INITIAL, ITERATE, scoped EDIT and POLISH. Reuse receipt `changes`/`todo` or the chat for actual writer and editor calls, model/effort, source version, reciprocal review and fidelity status. An unavailable or failed call leaves the affected stage incomplete. Preserve the existing state fields and authorization.

- Researcher decides when the draft is sufficient. No fixed max run count, convergence score, extra reviewer, or forced validation phase. A major deep reconstruction needs specific researcher authorization.
- Before final handoff, explicitly flag outstanding information necessary for methods transparency and reproducibility in **Researcher TODO** and remind the researcher to supply it; do not present affected methods as complete.
- Final concise receipt: mode/run + **current Word path**; approximate actual section-level textual modification for ITERATE; important changes; status of confirmed citations, Zotero collection and **actual dynamic fields**; whether `revision.md` has actionable items; missing inputs/blockers and any **Researcher TODO**. Distinguish completed, partial, and blocked operations. Do not report a Word/Zotero requirement as satisfied without actually performing it.
